This file documents the key prompts used while building the Kanban Task Board (React - Level 3).

1. Project Initialization

Prompt:

Create a React project using Vite and explain the folder structure for a Kanban task board app.

Purpose:

Understand project setup
Plan folder structure
2. Component Architecture

Prompt:

Design a component structure for a Kanban board with columns (To Do, In Progress, Done) and reusable task cards.

Purpose:

Build scalable component structure
3. State Management

Prompt:

Explain how to manage tasks using useState in React and handle multiple columns.

Purpose:

Learn state handling and updates
4. Add Task Feature

Prompt:

Write React code to add a new task using useState.

Purpose:

Implement task creation
5. Delete Task Feature

Prompt:

How to delete a task from a list using React state?

Purpose:

Update state correctly
6. Move Tasks Between Columns

Prompt:

Implement logic to move tasks between columns in a React Kanban board.

Purpose:

Handle task transitions
7. Edit Task Feature

Prompt:

How to implement inline editing of a task in React?

Purpose:

Improve interactivity
8. Priority System

Prompt:

Add priority levels (High, Medium, Low) with conditional styling in React.

Purpose:

Add business logic and styling
9. LocalStorage Persistence

Prompt:

How to store and retrieve tasks using localStorage in React with useEffect?

Purpose:

Maintain data after refresh
10. Drag and Drop

Prompt:

Implement drag and drop functionality in a React Kanban board.

Purpose:

Add advanced UI interaction
